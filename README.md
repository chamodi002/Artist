A backend API service for an \*\*Artist Website \& Event Ticketing Platform\*\* built using \*\*FastAPI, MongoDB Atlas, and JWT Authentication\*\*.



This backend provides APIs for artist event management, customer ticket booking, admin authentication, and ticket verification.



\---



\#  Project Overview



The \*\*Artist Ticketing Service Backend\*\* is the backend system of a full-stack event ticketing platform.



It manages:



\- Artist events

\- Ticket bookings

\- Seat availability

\- Booking status

\- Ticket reference generation

\- Admin authentication

\- Database communication



The frontend application is developed separately using \*\*Next.js\*\*.
